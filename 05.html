Project

The goal is to demonstrate data analysis skills required of virtually any data analysis project. Show this by doing the following data manipulations as well as a narrative that describes what you are doing at each step as you proceed. You only need to do a data manipulation one time with the syntax from the package of your choice.

  1. The easiest way to document your work is to do all R or Pandas instructions as a markdown file to document your work and write to a Word doc. Or, copy your R or Pandas instructions and output into a Word doc.
  2. Describe your data.
    • Brief paragraph description.
    • A codebook that describes the data (at least the variables of interest).
  3. Set up and document an R project (or Jupyter Notebook) and directory structure for the analysis.
  4. Read the data into R or Python.
    • Describe the conceptual data type of each variable of interest.
    • Describe the storage type within the computer of each variable of interest.
  5. Do any needed data cleaning such as making categorical responses consistent for a variable, not M, m, Male, and Man for responses to the male gender. Verify that each categorical variable in your analysis has "clean" data, such as with a bar chart.
  6. Convert all categorical variables of interest, integer or character value, to factors (R) or type category (Pandas).
  7. Do some other variable transformations, even if just changing units for continuous variables or recoding the levels of categorical variables.
  8. Subset the full data set to just variables of interest.
  9. Write the cleaned data to a feather file into the data folder for reading back into R or Pandas for the actual data analysis.
  10. For merging, either read two different data sets into R or Pandas data frames with a common variable and merge. Or, artificially create two data sets by doing a subsetting by moving some variables into one new data frame and the remaining variables into the other newly created data frame. Then merge back into a single data frame as if the data had arrived in separate files. Following that procedure provides examples of both subsetting and merging data frames.
  11. Data Analysis I: Display a bar chart or histogram for at least several variables of interest, and comment.
  12. Data Analysis II: Do a data aggregation and interpret.

Avoid the data dumps! At most you only need to show five or so records after a data manipulation. No need to display pages of data.

Turn In: A single .html or .docx file that contains the above steps, with the R input and abbreviated output.
