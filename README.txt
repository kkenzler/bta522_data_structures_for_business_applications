bta522_data_structures_for_business_applications
================================================

Portland State University course workspace for BTA 522:
Data Structures for Business Applications.

Current contents:
  kkenzler BTA 522 - Project.pdf
    Project write-up / submission artifact.

  05.html
    Week 5 project instructions page describing the required data-structure and
    data-analysis workflow.

  downloads/
    Local source data used for the project, including EPA air-quality files,
    NOAA weather-station files, and site metadata.

What this project appears to be:
  A data-structures / data-preparation course project built around real-world
  environmental data, with emphasis on directory structure, codebook thinking,
  data cleaning, data typing, transformation, subsetting, merging, and basic
  analysis/reporting.

Why it matters in a portfolio:
  This is the most ecologically aligned of the three BTA projects. It is useful
  for roles connected to environmental data, sustainability, climate, air
  quality, public-sector analytics, and other ecology-adjacent analysis work.

Primary artifacts:
  The project PDF is the current deliverable.
  The downloads folder is the practical evidence of the underlying source-data scope.
